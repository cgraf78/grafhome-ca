# AGENTS.md

## About

`grafhome-ca` is a Rust CLI that manages SSH certificate policy, enrollment,
renewal, and revocation around a Smallstep `step-ca`. It is personal
infrastructure published as a reference; the public tree must never contain
real site data.

## Layout

- `src/bin/grafhome-ca.rs`: the CLI. `src/` holds the library: `config`,
  `model`, `policy/`, `render`, `enrollment`, `enrollment_registry`,
  `runtime_provisioners`, `provenance`, `public_material`, and `smallstep`
  (the only module that shells out to `step`).
- `schemas/` (canonical policy schemas versioned under
  `schemas/policy/canonical/`), `templates/` (non-secret SSH, Apache,
  systemd, and Smallstep), `examples/site-config/` (the sanitized fixture
  tree), and `docs/`.
- `tests/`: Rust integration tests, plus `shell/` for the installer and
  release scripts. `scripts/`: release, packaging, and `termux-ci.sh`.

## Invariants

- No site data: fixtures use `example.test` names and RFC 5737 addresses.
  Never commit real policy, export bundles, hostnames, addresses, keys, or
  tokens.
- Smallstep is the crypto boundary; no signing in this repo.
- New policy fields go in the schema and `examples/site-config`, and old
  policy must stay readable by the new binary.
- Keep the dependency graph pure Rust (the release is a static musl build)
  and keep `jsonschema` default features off. Never enable `ssh-key` RSA
  support.
- Every public item needs rustdoc.

## Testing

- `cargo test --locked`, `cargo fmt --check`, and
  `cargo clippy --locked --all-targets --all-features -- -D warnings`.
- `RUSTDOCFLAGS='-D missing-docs' cargo doc --locked --no-deps`.
- MSRV: `rustup run 1.88 cargo check --locked --all-targets --all-features`.
- `cargo tree -q --locked --all-features --target all -i rsa` must print
  nothing; CI fails otherwise.
- Shell: `tests/shell/install-test` and `tests/shell/release-scripts-test`.
  CI also runs the full Rust matrix, including Termux via
  `scripts/termux-ci.sh`.
- CI-only integration tests, which skip silently unless both flags are set:
  `GRAFHOME_CA_RUN_SSH_REVOCATION=1 GRAFHOME_CA_REQUIRE_SSH_REVOCATION=1 cargo test --locked --test cli`
  (Linux, non-root, OpenSSH server installed) and
  `GRAFHOME_CA_RUN_STEP_CA_INTEGRATION=1 GRAFHOME_CA_REQUIRE_STEP_CA_INTEGRATION=1 cargo test --locked --test step_ca_integration`
  (the `step` and `step-ca` versions pinned in `test.yml`).

## Test isolation

- Tests use a temporary HOME, fake tools first on `PATH`, and `GRAFHOME_CA_*`
  path overrides. Use `--config-root examples/site-config` for manual runs.
- Never run against real CA state or as root.

## CI and generated files

- CI's ShellCheck job fails on any shell program missing from
  `.github/shellcheck-files.txt` (untracked files included) and on stale rows;
  no local runner detects this. Before pushing, run
  `bash <actions@lock>/.github/actions/shellcheck-inventory/run.sh "$PWD" .github/shellcheck-files.txt`
  from a cgraf78/actions checkout at the SHA in `.github/cgraf78-actions.lock`.
- `install.sh` is generated by the cgraf78/actions release installer, and the
  scripts listed in `scripts/.release-scripts.manifest` are vendored from it.
  The `cgraf78/actions sync` job byte-checks both; never hand-edit them.
  Repo-owned: `scripts/release.conf` and `scripts/release-smoke-hook.sh`.
  Regenerate with `consumer-ci/sync.sh <this checkout>` from cgraf78/actions
  at the locked SHA.
- `.github/cgraf78-actions.lock` and every `uses: cgraf78/actions/...@<sha>`
  move together, only via `consumer-ci/sync.sh`.
- `tests/shell/release-scripts-test` pins text in `test.yml` and
  `release.yml`, and requires `msrv-toolchain` to equal `Cargo.toml`'s
  `rust-version`; edit them together.
- The release payload (`scripts/release.conf`) must never ship state,
  secrets, or keys; key-shaped files in payload directories fail CI.
- `retry-infrastructure.yml` keys on the workflow name `Tests`; don't rename
  it.

## Release

`scripts/release.sh --dry-run`, then `scripts/release.sh --push`, which
pushes `main` and a `YYYYMMDD-HHMMSS-<8hex>` tag (UTC commit time and short
hash). `Cargo.toml`'s `0.1.0` is not the release version. The tag triggers
`release.yml`, which publishes per-platform archives with SHA-256 files and
GitHub artifact attestations.
